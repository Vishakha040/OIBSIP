Iris Flower Classification using Machine Learning¶

Oasis Infobyte Data Science Internship¶

Task 1¶

Objective¶

The objective of this project is to develop a Machine Learning classification model that predicts the species of an Iris flower based on its physical measurements.

The three target species are:

  • Setosa
  • Versicolor
  • Virginica

The project demonstrates the complete machine learning workflow, including:

  • Loading the Iris dataset
  • Exploratory Data Analysis (EDA)
  • Data Visualization
  • Feature Selection
  • Model Training
  • Model Evaluation
  • Model Comparison
  • Selection of the Best Performing Model

Feature Selection¶

The Iris dataset contains four numerical features.

  • Sepal Length
  • Sepal Width
  • Petal Length
  • Petal Width

From the visualizations above, Petal Length and Petal Width are the most discriminative features because they clearly separate the three Iris flower species.

Sepal Length and Sepal Width also contribute to classification but exhibit greater overlap between Versicolor and Virginica.

Therefore, all four features are retained for training the machine learning models.
