# Iris Flower Classification using Machine Learning

## Introduction

This project was completed as a part of my Data Science Internship at Oasis Infobyte.

The objective of this project is to build a machine learning model that can classify Iris flowers into three different species based on their sepal and petal measurements. The three species are Setosa, Versicolor, and Virginica.

## Dataset

The project uses the Iris dataset provided by the Scikit-learn library. It contains 150 flower samples with four features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target variable is the flower species.

## Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Steps Performed

In this project, I:

- Loaded the Iris dataset.
- Performed Exploratory Data Analysis (EDA).
- Checked the dataset for missing values.
- Generated statistical summaries.
- Visualized the data using histograms, box plots, pair plots, and a correlation heatmap.
- Split the dataset into training and testing sets.
- Trained Logistic Regression and K-Nearest Neighbors (KNN) models.
- Evaluated both models using accuracy score, confusion matrix, and classification report.
- Compared the performance of both models.

## Result

Both machine learning models performed well on the dataset and achieved high accuracy. After comparing their performance, the better-performing model was identified based on the evaluation metrics.
