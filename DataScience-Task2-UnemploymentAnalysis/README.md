# Unemployment Analysis with Python

## Introduction

This project was completed as a part of my Data Science Internship at Oasis Infobyte.

The objective of this project is to analyze unemployment data in India using Python. The project focuses on understanding unemployment trends by exploring the dataset, cleaning the data, and creating different visualizations to gain meaningful insights.

## Dataset

The dataset contains unemployment-related information across different states in India. It includes the following details:

- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area (Urban/Rural)

## Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Steps Performed

In this project, I:

- Imported the required libraries.
- Loaded the unemployment dataset.
- Explored the dataset.
- Checked the data types and missing values.
- Cleaned the dataset by removing missing values.
- Created visualizations to understand unemployment trends.
- Compared unemployment rates across different states.
- Analyzed unemployment trends over time.
- Compared unemployment in urban and rural areas.
- Used a correlation heatmap to understand the relationship between numerical features.
